탐구할 지진을 선택하세요
한반도에서 실제 발생한 지진입니다. 규모가 클수록 먼 관측소에서도 P·S파가 뚜렷하게 관측됩니다.
지도에서 관측소 3개를 직접 클릭하여 선택하세요
삼각측량에 사용할 관측소 3개를 지도에서 직접 클릭하세요. 세 관측소가 고르게 퍼져 있을수록 더 정확하게 진원의 위치를 결정할 수 있습니다.
아직 선택한 관측소가 없습니다. 지도 위의 파란 점을 클릭하세요. (0/3)
P파·S파 도달 시각과 PS시
PS시 = S파 도달 시각 − P파 도달 시각. 진원이 멀수록 PS시가 길어집니다.
관측소P파 도달(초)S파 도달(초)PS시(초)
진원거리를 직접 계산하세요
P파 속도는 6 km/s, S파 속도는 4 km/s 입니다. PS시를 이용하여 각 관측소의 진원거리를 직접 계산해 입력하세요.
진원거리 공식 유도
진원거리를 D라 하면, P파 도달 시간 = D/6, S파 도달 시간 = D/4 입니다.
PS시 = D/4 − D/6 = D(3−2)/12 = D/12
따라서 D = PS시 × 12 (km)
(일반식: D = PS시 × V_P·V_S / (V_P − V_S))
* 입력한 값은 다음 단계의 원의 반지름으로 사용됩니다.
좌표계의 원점을 설정하세요
원의 방정식을 세우려면 원점 (0, 0)을 어디로 정할지 결정해야 합니다. 지도는 마우스 휠/손가락으로 확대·축소할 수 있습니다.
원점을 선택하면 각 관측소의 좌표(km)가 표시됩니다.
각 관측소를 중심으로 하는 원의 방정식을 직접 작성하세요
관측소 좌표 (a, b)와 진원거리 r로 원의 방정식 (x−a)² + (y−b)² = r² 을 작성하세요.
✏️ 제곱은 ^2 로 입력하세요. 예) (x-120)^2 + (y-45)^2 = 131^2
소수는 반올림하여 소수점 둘째 자리까지 나타내세요. [^2 넣기] 버튼을 사용할 수 있습니다.
내가 작성한 방정식 그대로 원이 그려집니다. 세 원이 한 점 근처에서 만나는지 확인하세요.
내가 작성한 원의 방정식 (참고)
두 원의 방정식을 빼서 공통현(직선)의 방정식을 구하세요
두 원의 방정식을 빼면 2차항이 소거되어 두 원의 교점을 지나는 직선(공통현)의 방정식이 됩니다.
계산 과정을 서술하고 결과를 ax + by = c 형태로 정리하세요.
💡 소수가 나오면 반올림하여 소수점 둘째 자리까지 나타내세요.
내가 구한 공통현 방정식 (참고)
두 공통현을 연립하여 교점을 구하세요
위의 공통현 방정식들을 두 개씩 연립하여 교점 3개를 각각 구해 입력하세요. 세 교점을 입력하면 자동으로 평균 진앙이 지도에 표시됩니다. 소수는 반올림하여 소수점 둘째 자리까지 입력하세요.
진앙 결정 — 실제 진앙 위치는 여기서 처음 공개됩니다! ⭐
세 교점의 평균이 여러분이 구한 진앙이에요. 아래 지도에서 실제 진앙(⭐)과 비교해보세요.

진원의 깊이 — 반구 모형으로 진원 위치 특정하기
한 관측소를 기준으로 진원거리(d)를 반지름으로 하는 반구를 세우고, 진앙을 지나는 현(chord)을 그린 뒤, 그 현을 지름으로 하는 원을 이용해 진원의 위치를 직접 특정해봅니다.
진앙 위치는 실제 진앙 데이터를 사용합니다.
